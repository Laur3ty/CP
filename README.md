# Sorriso Recorrente · Site (Front-End Design Engineering, Sprint 1)

Site em **HTML e CSS**, versão **desktop**, criado para o Challenge FIAP × Turma do Bem (1TDSPR).

## Objetivo do projeto

O **Sorriso Recorrente** é uma plataforma para a **Turma do Bem** transformar doadores pessoa física pontuais em doadores mensais e manter quem já contribui. Em vez de depender apenas do contato humano e de campanhas avulsas, nosso projeto organiza o relacionamento com o doador e mostra, de forma simples, o impacto que a doação dele gera.
